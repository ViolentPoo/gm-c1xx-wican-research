# WiCAN Source Index

Primary upstream source:

- `https://github.com/meatpiHQ/wican-fw`

Capabilities relevant to this project from upstream README/documentation links:

- WiCAN Pro supports additional protocols and buses compared with original WiCAN.
- RealDash CAN protocol.
- `slcan` / SocketCAN support on pins 6/14.
- SD card logging on WiCAN Pro.
- GM HS J1962 pins 12/13, MS-CAN pins 3/11, and SW-CAN/GMLAN pin 1 listed for WiCAN Pro.

Project-specific limitation:

- Passive capture may require temporary mode changes from normal AutoPID operation.
